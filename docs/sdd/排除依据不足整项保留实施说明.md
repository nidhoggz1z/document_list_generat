# 排除依据不足时整项保留（2026-10-27）

> 历史实施记录：本口径已由用户后续确认的 [严格排除与一级目录过滤](./严格排除与一级目录过滤实施说明.md) 替代，不再用于新任务。

用户确认：同一材料只要任何一个相关对象无法确认排除，就对该项的全部相关对象保留；已有充分依据的其他对象也随整项保留。

具体包括模型同时返回部分 `instances` 和部分有充分证据的 `excludedObjects`：只要存在保留实例，所有已排除对象也要恢复，不能继续做同一规则内的逐对象筛选。

在共享 `validate_material_decisions` 中处理规则级 `EXCLUDE` 和 `KEEP.excludedObjects`：先校验规则、对象、引用的真实性及作用范围，再判断排除证据是否充分。发现任何对象缺少有效的明确事实时，将整项规范化为 `KEEP`，清空对象排除，按原作用范围内的全部对象生成或保留材料实例。无已知对象时保留一条通用材料。沿用原清单材料名、要求、制度依据，现有合法实例的细化要求与展示字段保留；理由标注“排除依据不足，整项暂予保留，待人工确认”。

未知或明确缺失的事实不能支持排除，但真实引用的未知事实可触发保留。用户后续确认两类也整项保留：排除引文与原文不一致、模型漏掉部分相关对象。前者丢弃不可靠的排除内容，使用原清单和已知对象构造真实引用；后者丢弃该项不完整的模型细化内容，按原要求重建全部相关对象材料。保留实例的伪造来源、跨产品或对象引用、重复/漏规则、格式错误、核查项混入材料继续按现有错误处理。保持 API 字段与目录结构，不将未确认材料标记为确定不适用；不修改历史任务。
